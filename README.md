# 簡易クラスター分析ツール (Hierarchical Cluster Analysis) 利用者マニュアル＆チュートリアル

本ツールは、多次元のデータセット（顧客アンケート、店舗別売上、製品スペック、地域統計など）から、データの類似性に基づいて自動的にグループ分け（階層クラスター分析）を行い、その特徴を可視化するWebアプリケーションです。

データを外部サーバーへ送信せず、すべてお使いのWebブラウザ内（ローカル環境）で安全に高速処理します。

## 1. 本ツールの特長

* 🔒 **安心のセキュア設計**: データを外部にアップロードしない完全クライアントサイド処理。社外秘データや顧客情報も安心して利用可能です。
* 📋 **Excelから直接コピペOK**: 範囲選択してコピー（Ctrl+C）し、そのまま貼り付け（Ctrl+V）するだけで即時インポート。
* 🌳 **インタラクティブなデンドログラム**: 樹形図（デンドログラム）を見ながら、スライダー操作で動的にクラスター数（分割ライン）を変更し、色分けをリアルタイムで確認できます。
* 🤖 **最適クラスター数の自動判定**: シルエット係数（Silhouette Score）などの指標をもとに、データ構造に最も合致する最適なクラスター数をシステムが自動推奨します。
* 📊 **豊富なプロファイリング可視化**: 「クラスターごとの平均値ヒートマップ」「レーダーチャート」「PCA/UMAPによる2次元散布図」を用い、分割されたグループの特徴を直感的に解釈できます。

## 4. 画面1：データインポート ＆ 前処理

### 4-1. データ取り込み（3通りの方法）

分析対象のデータは以下の方法で読み込めます。各行の1列目はサンプル名（顧客名、店舗名など）として扱われ、2列目以降が数値データとなります。

1. **ファイルドラッグ＆ドロップ**: `.csv`, `.xlsx`, `.xls` ファイルをドロップするかクリックして選択します。
2. **Excelコピペインポート**: Excelのセル範囲をコピーし、専用のテキスト枠に貼り付けて読み込みます。
3. **サンプルデータ**: 「主要都市別 ライフスタイル調査」「EC顧客別 購買行動分析」「ワインの品質・成分データ」などのデモデータを1クリックで呼び出せます。

### 4-2. データの単位合わせ（前処理変換）

異なる単位（例：売上金額と5段階評価）を持つ変数を公平に比較するため、読み込み時にデータを補正します。

* ✨ **標準化 (Z-Score) [推奨]**: 各変数の平均を0、標準偏差を1に変換し、単位や桁数を揃えます。
* 📏 **Min-Max 正規化**: 最小値を0、最大値を1となるようにスケーリングします。
* 📈 **対数変換 + 標準化**: 巨大な外れ値を持つデータ（例：年収やフォロワー数）の指数的な影響を和らげます。
* 🛡️ **ロバスト標準化**: 外れ値の影響を受けにくい中央値と四分位範囲を使用します。

※ データセットプレビュー画面の表のチェックボックスを外すことで、分析から特定の変数を除外することもできます。

## 5. 画面2：階層クラスター分析 ＆ デンドログラム

### 5-1. 分析モードの設定（手法・距離）

データの性質や目的に合わせてクラスタリングのロジックを選択します。よくわからない場合はプリセットから選んでください。

* **標準モード (ウォード法 × ユークリッド距離)**: 値の大きさや全体的な量で分類します。最も一般的でバランスの良い結果が得られます。
* **パターン重視モード (群平均法 × コサイン類似度)**: 全体的な規模ではなく、「波形」や「比率のパターン」が似ているものをまとめます。
* **カスタム**: ウォード法、群平均法、最遠隣法などの「結合手法」と、ユークリッド、マンハッタン、コサインなどの「距離尺度」を自由に組み合わせられます。

### 5-2. デンドログラムとクラスタ数の決定

計算が完了すると樹形図（デンドログラム）が描画されます。

* ✂️ **クラスタ数 (k) スライダー**: スライダーを動かすか、デンドログラムのグラフ上をクリックすることで、樹形図を切断する高さを変え、グループ数（k）を動的に調整できます。
* 🤖 **推奨クラスタ数ボタン**: 統計的指標（シルエットスコアと結合高さのギャップ）に基づき、最適なクラスタ数へ自動的にスライダーをセットします。

## 6. 画面3：クラスタ特徴の可視化 (プロファイリング)

作成された各クラスターが「どのような特徴を持っているか」を解釈するためのダッシュボードです。

### 6-1. PCA / UMAP 2次元散布図マップ
* 多次元のデータを2次元の平面に圧縮し、クラスターが空間上でどのように分布しているかを可視化します。
* 点の集まりや境界線を見ることで、クラスター分けの妥当性を視覚的に確認できます。

### 6-2. レーダーチャート（プロファイル比較）
* クラスターごとの「平均的な特徴」をレーダーチャートで重ねて表示します。
* どのグループがどの変数に特化しているか（例：「グループAは価格重視、グループBは品質重視」など）が一目で分かります。

### 6-3. ヒートマップ（クラスター別平均値）
* 縦軸に変数、横軸にクラスターを配置したカラーテーブルです。
* 全体平均と比較して値が高い項目は赤色、低い項目は青色でハイライトされ、詳細な数値傾向を読み取れます。

## 7. 結果のエクスポート（Excel出力）

「Excel形式 (.xlsx) でダウンロード」ボタンを押すと、分析結果全体を含むExcelファイルが出力されます。

出力されるファイルは以下の3シート構成です：
1. **全データと割当**: 元のデータに、所属する「Cluster（クラスター番号）」列が追加されたマスターデータ。
2. **クラスタ要約統計**: クラスターごとの各変数の平均値とサンプル数がまとめられた集計表。
3. **分析設定**: 分析に使用した手法や前処理モードなどのメタデータ。

## 8. よくある質問（FAQ）

### Q1. エクセルからコピーして貼り付けたのにエラーになります。
**A.** コピーした範囲の1行目に「変数名」、1列目に「サンプル名」が含まれているかご確認ください。データ部分だけのコピーでは正しく解析できません。

### Q2. デンドログラム上で特定サンプルのラベルが重なって見えません。
**A.** サンプル数が多い場合（概ね50件以上）、画面幅に収めるためにラベルが重なることがあります。グラフ右上のツールバーからズーム機能を使用するか、スライダー上の「クラスタ数」での色分けを利用して大局的な構造を捉えるようにしてください。

### Q3. 「標準化」と「パターン重視モード」の違いは何ですか？
**A.** 前処理の「標準化」は異なる単位の変数を同じ尺度に乗せるためのものです。一方、「パターン重視モード（コサイン類似度）」は、値の絶対的な大小に関わらず、複数の変数間の「割合（構成比）」が似ているものを同じグループとみなす計算方法です。

## 9. ディレクトリ構成と使用ライブラリ

### ディレクトリ構成
```text
cluster-app/
├── index.html        # メインのアプリケーション画面
├── css/              # スタイルシート
├── js/               # メインロジック (clustering.js, dendrogram.js など)
├── lib/              # 外部ライブラリ群
├── data/             # その他データ
└── README.md         # 本ドキュメント
```

### 使用ライブラリ（フロントエンド）
本ツールは以下のオープンソースライブラリを使用しています。
* **[Plotly.js](https://plotly.com/javascript/)**: インタラクティブなグラフ描画（デンドログラム、レーダーチャート等）
* **[UMAP-JS](https://github.com/PAIR-code/umap-js)**: 次元圧縮（UMAP散布図の描画）
* **[PapaParse](https://www.papaparse.com/)**: CSVファイルの読み込み・解析
* **[SheetJS](https://sheetjs.com/)**: Excelファイルの読み込み・出力解析

※ 階層クラスター分析のコアロジック（距離行列計算・ウォード法等の結合処理）は、外部APIに依存せず専用JavaScriptロジックとして実装されています。
